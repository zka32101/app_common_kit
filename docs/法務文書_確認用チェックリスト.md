# 法務文書（プライバシーポリシー・利用規約）確認用チェックリスト

> **これは法的助言ではありません。** 公開する文書は、弁護士など専門家の確認を経てください。
> キットが提供するのは、文書へのリンクを設定画面に出す部品（`LegalLinks` / `LegalSection`）だけです。
> 文面そのものはキットに含めません（アプリごとに、扱うデータ・収益化・運営者の事情が違うため）。

## 1. 文書をアプリに載せる

```dart
SettingsScreen(
  appName: '…',
  legal: const LegalLinks(
    privacyPolicyUrl: 'https://…/privacy',   // https のみ
    termsUrl: 'https://…/terms',
    commercialDisclosureUrl: 'https://…/tokushoho', // アプリ内課金があるとき
    contactUrl: 'https://…/contact',
  ),
  onOpenLink: (uri) => launchUrl(uri, mode: LaunchMode.externalApplication), // url_launcher
)
```

## 2. プライバシーポリシーに書く事実の洗い出し（アプリごとに確認）

文面を作る前に、アプリが実際に何をしているかを事実として確認する。専門家へ渡す材料にもなる。

| 確認項目 | キットの該当機能 | 確認すること |
|---|---|---|
| 端末内の保存 | 学習記録・設定・ながら学習 | 端末内のみか、外部送信があるか |
| 広告 | `google_mobile_ads`（AdMob） | 広告識別子の利用、同意（UMP）、年齢の扱い |
| 課金 | `purchases_flutter`（RevenueCat） | 購入情報の扱い、復元 |
| 分析 | `Analytics`（Firebase Analytics など） | 送るイベント、同意前は送らない（`backend` を null） |
| クラッシュ収集 | `CrashReporter` | 送る内容、個人情報の除去（メール等は伏せる実装あり） |
| フィードバック | `FeedbackFormPage`（Firestore） | 送る項目（利用者ID・端末・バージョン）、保管期間 |
| アカウント | アプリ固有（例: kanken の Firebase Auth） | 取得する識別子、削除の方法 |
| 第三者提供・委託 | 上記の各サービス | 提供先の一覧 |
| 子ども | 対象年齢 | 保護者の同意・年齢制限の表示 |

## 3. ストア側で必要になるもの（要確認）

- **App Store**: App のプライバシー（栄養成分表示に相当する申告）、プライバシーポリシーの URL。アプリ内でアカウントを作れる場合は、アプリ内からアカウント削除を開始できること。
- **Google Play**: データセーフティの申告、プライバシーポリシーの URL。アカウント作成がある場合は、アプリ内とウェブの両方からの削除手段。
- キットの `DataDeletion` / `SettingsScreen(dataDeletion:)` は、アプリ内の削除導線の部品。サーバー側のアカウント削除は、アプリが `CallbackEraser` に実装する。

## 4. 利用規約・特定商取引法に基づく表記（要確認）

- 試験団体・出題元との関係（非公式であること）の明記。`SettingsScreen(disclaimer:)` で「このアプリについて」に出せる。
- 合格を保証しないこと、内容の正確性の範囲、免責。
- アプリ内課金（買い切り・期間付き）の条件、解約・返金の扱い。ストア経由の購入の取り扱い。
- 特定商取引法に基づく表記の要否と、運営者情報の出し方（個人運営での表示の扱いは専門家に確認する）。

## 5. 公開前の最終確認

- [ ] 文書の URL が https で開ける（`LegalLinks.isValidUrl`）
- [ ] 文書の内容が、2 の表の事実と一致している（機能を足したら文書も更新する）
- [ ] 専門家の確認を受けた（日付・確認者を控える）
- [ ] 多言語で出すアプリは、各言語の文書を用意した（機械翻訳のまま公開しない）
- [ ] ストアの申告（プライバシー・データセーフティ）と文書が食い違っていない
